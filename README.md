# Silabeador

Juego de aula para practicar la division en silabas (por golpes de voz), la
silaba tonica y la clasificacion de palabras en agudas, llanas y esdrujulas.

- Cuatro actividades: Clasificar, Dividir en silabas, Silaba tonica y Todo junto.
- Cuatro modos: Contrarreloj, Muerte Subita, Supervivencia y Practica
  (en Practica, cada error se explica paso a paso).
- Tres niveles de dificultad (o Mixto).
- Sin cuentas ni base de datos: el ranking y los ajustes se guardan en el navegador.

Las palabras proceden del diccionario es_ec (Hunspell) y se han filtrado con la
lista de frecuencias de FrequencyWords (Hermit Dave, a partir de OpenSubtitles 2018,
licencia CC BY-SA 4.0).
